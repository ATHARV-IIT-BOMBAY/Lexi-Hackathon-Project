**Lexi** is a multi-sensory, gamified handwriting therapy platform that uses real-time clinical telemetry to help children with **dyslexia** and **dysgraphia** build confidence in writing. 

With the help of **Lexi**, our friendly AI companion, children get real-time audio and visual feedback while practicing their strokes in a fun, rewarding environment! 🎨✏️

---

## 🌟 Key Features

| Feature | Description |
| :--- | :--- |
| 🎮 **6 Learning Modes** | Trace Shapes, Letters, Numbers, Words, Sentences, and free-form Drawing! |
| 🌍 **5 Languages** | Supports English 🇬🇧, Spanish 🇪🇸, French 🇫🇷, German 🇩🇪, and Italian 🇮🇹! |
| 📊 **13 Clinical Metrics**| Real-time analysis of pen strokes, accuracy, time on task, tremors, and more. |
| ✍️ **Custom Engine** | A robust HTML5 Vector Engine tailored for precise handwriting tracking. |
| 🗣️ **Meet "Lexi"** | An interactive AI avatar offering voice encouragement and celebration effects! |
| 🧠 **Orton-Gillingham** | Inspired by proven, multi-sensory literacy instruction methods. |

---

## 🛠️ Tech Stack

- ⚛️ **Frontend:** React 19 + Vite
- 🖌️ **Drawing:** Custom Canvas Vector Engine
- 🔊 **Audio:** Web Audio API & Speech Synthesis API
- 🎨 **Styling:** CSS3 Glassmorphism UI
- 💾 **Storage:** `localStorage` (Offline-first data persistence!)

## 🚀 How to Run Locally

Get up and running in just a few seconds!

```bash

npm install

# 2. Start the development server
npm run dev
```

> **Note:** Open [http://localhost:5173](http://localhost:5173) in your browser. Click **"Try Live Demo"** on the landing page to instantly jump in!

## 💡 The Problem We Are Solving

Dyslexia affects 15-20% of the population. While most AI tools focus solely on *reading* assistance (like text-to-speech or font changes), children with dyslexia often also struggle with **dysgraphia** — difficulty with the physical act of writing. 

Lexi bridges this gap by focusing on the physical mechanics of handwriting. By combining the proven **Orton-Gillingham multi-sensory methodology** with cutting-edge, real-time stroke telemetry, we help children build the necessary neural pathways for writing confidence.
